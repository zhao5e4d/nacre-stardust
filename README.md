# NACRE 星隙 — 深空突围

一个以原创硬表面星舰「游隼 P–04」为主角的浏览器 3D 小游戏。

在线体验：[NACRE 星隙 — 深空突围](https://nacre-peregrine-stardust.zhao5e4d.chatgpt.site)（当前为仓库所有者私有访问）

## 打开游戏

Windows 双击 **Start Game.cmd**，会启动本地服务并打开浏览器。当前项目已提供构建后的静态网页，默认地址为 **http://127.0.0.1:4173/**。

也可以运行：

```sh
npm install
npm run dev
```

开发地址为 **http://127.0.0.1:5173/**。推荐新版 Chrome / Edge，需支持 WebGL 2。运行时的模型、代码和音效均在本地，无外部 CDN、付费 API 或登录依赖。

## 任务与操作

穿越 6,000 米碎星带，击落至少 12 架无人机，启动跃迁。大约 3 分钟一局。若抵达终点时击杀数不足，会继续拦截战，直到满足条件。

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 左右、上下移动 |
| 鼠标移动 | 瞄准；准星附近提供少量辅助锁定 |
| 空格 / 按住鼠标左键 | 双轨脉冲炮；持续开火会过热 |
| Shift | 加力推进，消耗能量，松开自动恢复 |
| Q | 相位冲击波；清除附近敌机、陨石和弹幕，12 秒冷却 |
| C | 切换追尾与座舱视角 |
| Esc / P | 暂停 / 继续 |

手机和平板使用屏幕左侧摇杆、右侧射击与加速按钮。青色导航环可修复 18 点舰体并补充 32 点能量；击落连击最高 5 倍得分。最高分保存在当前浏览器本地。

舰桥模式支持拖动旋转、滚轮缩放、双指缩放、三种涂装和自由鉴赏。右下角可以切换高画质与流畅模式。页面失去焦点或切到后台会自动暂停任务。

## 原创模型路线

本项目采用代码驱动的硬表面建模，而非调用图生 3D 服务，也没有沿用参考项目的舰船资产。

1. 在 `game/ship.mjs` 定义原创舰船轮廓与各个结构。
2. 用带倒角的挤出装甲、独立管线、散热栅、紧固件、炮管、引擎涡轮和驾驶舱玻璃组成模型。
3. 将 679 个构件按 12 种 PBR 材质合并，约 36,364 个三角面。
4. 导出为 `public/models/peregrine.glb`，约 3.5 MB，可导入 Blender 等软件继续编辑。
5. 在 Three.js 中加载模型，增加离子尾焰、灯光、环境反射、泛光、冲击波和战斗玩法。

模型源文件、可编辑 GLB 和参数均在项目中。舰体几何、界面、星空与行星着色器、音效均为本项目编写。GLB 加载失败时会用同一建模源代码即时构建模型。独立 GLB 不包含运行时尾焰和甲板文字贴标。

## 开发与构建

```sh
npm run model:export   # 修改舰船源代码后重新导出 GLB
npm test              # 战斗、状态切换、完整航程与模型检查
npx tsc --noEmit      # 类型检查
npm run build         # 静态输出到 dist/client
npm start             # 本地预览构建产物，端口 4173
```

部署时上传 **dist/client** 目录的全部内容到静态网站服务。ES Module 和 GLB 需要 HTTP 服务，不要用 `file://` 双击 HTML。没有服务端数据、账户或数据库。不要只复制 `index.html`。

主要文件：

- `app/page.tsx`、`app/globals.css`：舰桥、游戏 HUD、触控、帮助与结算。
- `game/ship.mjs`：原创星舰可编辑建模源码。
- `game/engine.mjs`：Three.js 渲染、输入、相机、资源管理和表现效果。
- `game/simulation.mjs`：独立战斗模拟、碰撞、计分、修复、跃迁状态机。
- `game/world.mjs`：星空、行星、碎石、无人机和推进器。
- `game/audio.mjs`：Web Audio 合成音效。
- `tests/simulation.test.mjs`：9 项自动检查，包含不跳过战斗与伤害判定的完整通关模拟。
